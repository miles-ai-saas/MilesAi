# Superpowers 过程文档

实施中的 **design / plan** 放在本目录：

- `specs/YYYY-MM-DD-<topic>-design.md` — 设计
- `plans/YYYY-MM-DD-<topic>.md` — 实施计划

**合入后**：删除对应过程文档；把仍需长期保留的**功能 / 契约说明**写入 `docs/guides/`（或 `docs/architecture/` / `backend/tests/README.md`），勿把 Task 清单与红绿步骤搬进 guide。

空的 `specs/`、`plans/` 仅作落盘位置；已落地能力请从 guides 阅读。
