# 多模态产品能力说明

> 类型：产品能力 | 状态：**核心能力已上线**（识图、生图/图生图、生视频/首尾帧、媒体资产、生视频异步任务、SSE 进度/取消、任务中心、视频升格 KB）  
> 立项对照：[prd.md](./prd.md)（§模块6b 多模态差异速查；PRD 愿景较全，以本文「实现状态」为准）

本文从 **产品视角** 说明平台多模态能力：用户能做什么、在哪里做、与知识库入库的区别。不涉及签名下载等实现细节。

## 1. 能力总览

平台「多模态」拆为 **四类能力**，请勿混为一谈：

| 能力类 | 用户价值 | 典型入口 | 实现状态 |
|--------|----------|----------|----------|
| **生文** | 问答、总结、RAG、工具调用 | 智能体对话、流程 LLM 节点 | ✅ 已支持 |
| **识图** | 上传图片 + 文字，让模型「看懂」并回答 | 智能体对话、流程调试/运行 | ✅ 已支持（检索仍基于文本） |
| **生图 / 生视频** | 根据描述或参考图/首尾帧生成新文件 | 智能体工具、流程 `ImageGenerate` / `VideoGenerate` | ✅ 万相 + 豆包；文生图、图生图、文生视频、图生视频、首尾帧 |
| **资料入库** | 把图/音/文档放进知识库，检索时当「资料」引用 | 知识库上传 | ✅ 已支持（图/音多为 OCR/转写文本，非原图进模型） |

## 2. 生文（已支持）

### 2.1 是什么

用大语言模型根据 **文本** 生成回答，可结合：

- 知识库检索（RAG）
- 已发布流程画布
- 平台工具 / 技能包（可选）
- 子智能体协同（DeepAgents）

### 2.2 在哪里用

| 场景 | 入口 |
|------|------|
| 日常对话 | 工作台 → 智能体 → 对话 |
| 自动化流程 | 流程画布 → `LLMCall` 节点 |
| 绑定流程的智能体 | 智能体配置「已发布流程」后，对话走画布 |

### 2.3 模型要求

模型类型为 **大语言 / 推理**（`llm`、`reasoning`），在「模型供应商」中选择并绑定到智能体或节点。

### 2.4 当前限制

- 对话与流程 LLM 的 **回答主体为文本**；图片/视频以 **附件或生成物** 形式展示，非流式嵌入正文。
- 多轮对话 **不自动携带** 上一轮附图（以当轮 `media` 为准）。

## 3. 识图（已支持）

### 3.1 是什么

用户在提问时 **附带一张或多张图片**，系统选用 **视觉理解（vision）** 模型，将图片与文字一并送入模型，得到文字回答。

**不是**：把图上传到知识库再等检索（那是 §5）。

### 3.2 支持的场景

| 场景 | 用户操作 |
|------|----------|
| 智能体对话 | 输入框上传图片 + 输入问题 → 发送 |
| 流程调试 | 调试面板上传附图 + query；`LLMCall` 等节点接收 `media` |
| 智能体 + 知识库 | 文字检索资料 + 当轮附图一并送入模型（检索仍基于文字） |

### 3.3 模型与配置

- 需在「模型供应商」中选择 **图像理解（vision）** 类模型（如通义 VL、豆包视觉等）。
- 若智能体绑定的是纯文本模型，附图时将提示更换模型。

### 3.4 附件与预览（产品约定）

- 图片先作为 **附件** 上传（与对话、流程用途区分），不占知识库文档列表。
- **暂不采用「签名下载链接」** 对外暴露文件；预览与模型读图由服务端在授权后从对象存储读取（前端通过鉴权 `GET .../attachments/{id}/content`）。
- 单轮附图数量、大小设上限（如最多 4 张、单张 ≤10MB）。

### 3.5 未包含 / 已增强（识图）

- 对话中上传 **视频** 让模型直接观看：仍未支持。
- **多轮沿用附图（已支持）**：智能体配置「多轮识图沿用附图」（默认开）；用户未传新图时自动带上一条用户消息中的图片。

## 4. 生图与生视频（已支持）

### 4.1 是什么

调用 **图像生成 / 视频生成** 类模型，产出 **新文件**（图片或视频），可在对话、流程调试结果或「生成素材」中查看。

| 能力 | 输入 | 输出 |
|------|------|------|
| **文生图** | 文本 prompt | 图片附件 |
| **图生图** | prompt + 参考图 attachment | 图片附件 |
| **文生视频** | 文本 prompt | 视频附件 |
| **图生视频** | prompt + 首帧图 attachment | 视频附件 |
| **首尾帧生视频** | prompt + 首帧 + 尾帧 attachment（须同时提供首帧） | 视频附件 |

### 4.2 支持的场景

| 场景 | 用户操作 |
|------|----------|
| 智能体对话 | 描述需求 → 模型调用 `generate_image` / `generate_video` → 回复中带预览 |
| 流程画布 | `ImageGenerate` / `VideoGenerate` 节点；可连线注入 prompt、参考图、首尾帧 |
| 模型供应商 | 配置 `image_gen` / `video_gen` 及 API Key |
| 生成素材 | 工作台「生成素材」列表；图片/视频可升格写入知识库（视频为描述 Markdown，见 §4.6） |
| 任务中心 | 工作台 → **任务中心** → **生成任务**：列表、进度、取消、详情预览（`?category=generative&job=<id>` 可深链） |

### 4.3 与「识图」区别

| | 识图 | 生图/生视频 |
|---|------|-------------|
| 方向 | 用户给图，模型 **理解** | 模型 **创造** 新图/视频 |
| 模型类型 | vision | image_gen / video_gen |
| 等待 | 通常秒级 | **生图 / 生视频** 默认 **异步**（`generative_jobs`）；生视频常 1–5 分钟，生图视模型与张数为数秒～数十秒；对话/流程内轮询或 SSE，**任务中心** 可统一查看；调试可将 `async_generative` 或环境变量 `generative_*_async=false` 切回同步 |

### 4.4 安全与确认（产品）

- **生视频** 工具默认 **直接入队** 执行（开启生视频即同意调用）；确认卡片不再出现；进行中任务可取消。
- **生图** 默认可直接执行；尺寸单边 ≥1280px、总像素大于 1024² 或一次 ≥3 张时 **需用户确认**。
- 生成 prompt 走合规扫描（`generative` 场景，与对话词库绑定可配置）；租户日配额：`generative.daily_limit_per_tenant`（0 为不限）。
- **进行中任务** 可在详情中 **取消**；进度通过 SSE 或轮询更新（非逐帧视频预览）。

### 4.5 未包含（生成 v1）

- 在普通 LLM 节点里「一句话顺带出图」（须走生成工具或专用节点）。
- 生成结果 **默认不入库**（须在「生成素材」中手动升格；图片为原图入库，视频为 **描述文档** 入库供 RAG，原 mp4 仍在附件）。
- 视频 **逐帧/流式** 预览。
- **LLM 真 token 流式**（📋）：WS v1 已上线（[features/agent-chat-websocket.md](../features/agent-chat-websocket.md)），`chat.delta` 仍为整段模拟；生成任务进度用 SSE。
- **视频封面**：生成视频后若环境有 `ffmpeg` 会抽首帧写入 `cover_attachment_id`，供「生成素材」列表缩略图。

### 4.6 视频升格知识库（产品说明）

- **不是**把 mp4 当作 vision 输入做检索。
- **是**将生成时的 prompt、模型、任务元数据等整理为 **Markdown 描述文档** 写入知识库，供 RAG 文本检索；成片仍在附件与「生成素材」中播放。
- 在「生成素材」对视频资产执行「升格入库」即可（与图片升格入口相同，后端策略不同）。

## 5. 多模态知识库（已支持，属另一类能力）

### 5.1 是什么

将 **文档、图片、音频** 等上传到 **知识库**，系统解析为文本分片并建立向量索引；智能体或流程在回答时 **检索相关片段**，注入 prompt。

### 5.2 用户感知

- 「根据公司内部 PDF/图片资料回答」→ 用知识库 + RAG。
- 图片在库内多数经 **OCR/占位转写** 成文字再检索，**不是**把原图在对话时送给 vision 模型。

### 5.3 支持格式（摘要）

详见 [knowledge-base.md](../guides/knowledge-base.md)：TXT/PDF/常见图片/音频等；部分能力需 Worker 安装可选依赖 `[multimodal]`。

### 5.4 与 PRD 差距（产品预期管理）

| PRD/市场表述 | 当前产品 |
|--------------|----------|
| 以图搜图 | 未作为独立产品能力 |
| 文本搜图 | 未作为独立产品能力 |
| 视频文件入库解析 | 上传白名单未含视频 |

## 6. 按角色使用建议

| 角色 | 建议 |
|------|------|
| **业务用户** | 日常问答、客服：生文 + 知识库；需理解用户发的图：为智能体配置 vision 模型并附图提问 |
| **流程搭建者** | RAG 用现有节点；海报/短视频：拖入生图/生视频节点或让智能体调用生成工具；含生视频时默认异步，调试面板可轮询，也可到任务中心查看 |
| **管理员** | 维护 vision / image_gen / video_gen 模型与 Key；关注 `generative.daily_limit_per_tenant`、工具确认策略；排障用 **任务中心 → 生成任务** |

## 8. 技术定位、代码域与运维（研发）

### 8.1 能力 → 代码域

| 能力 | 主要代码域 |
|------|------------|
| 生文 | `ainvoke_chat`、`tenant/agents/services/agent/` |
| 识图（输入） | `integrations/chat/multimodal.py`、`flow_runtime/nodes/llm_nodes.py` |
| 生图 / 生视频（输出） | `integrations/generative/`（万相 + 豆包 `volcengine_video`） |
| 资料入库 | `app/rag/parse/`、`media_assets` |

共享基础设施：

```text
integrations/chat/multimodal.py   # build_user_message、resolve_media_refs
tenant/attachments/...            # 上传、GET .../content 读字节
integrations/generative/          # 生图/生视频 + quota + volcengine_client
media_assets                      # 生成物目录 + promote-to-kb（图片）
```

### 8.2 运维

| 操作 | 命令 / 配置 |
|------|-------------|
| 历史生成物登记 | `python cli.py backfill-media-assets [--dry-run]` |
| 生成日限额 | `system_config` → `generative.daily_limit_per_tenant`（0=不限） |
| 迁移 | `python cli.py migrate`（含 `media_assets` 表） |
