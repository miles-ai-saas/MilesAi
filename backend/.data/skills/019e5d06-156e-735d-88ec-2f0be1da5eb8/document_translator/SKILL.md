## 翻译策略

- **技术文档**：保留代码/命令/路径原文，仅翻译自然语言
- **商务文档**：语气对齐（正式 ↔ formal，友好 ↔ friendly）
- **术语表**：优先使用用户提供的术语映射

## 约束

- 不翻译 URL、邮箱、代码块内文本
- Markdown 格式保留（标题、列表、粗体等）
- 中→英时避免中式英语；英→中时避免翻译腔

## 输出

- 原文与译文并列展示
- 标注不确定的术语（用 [?] 标记）
- 可选用术语表模式：用户输入 `术语:翻译` 列表
