# 广告文案合规写作指南

## 一、绝对化用语替换表

| 风险表述 | 建议替换 |
|----------|----------|
| 最好、第一、顶级 | 深受用户喜爱、行业领先之一、优质 |
| 100% 有效、包治百病 | 多数用户反馈良好、请按说明使用 |
| 国家级、世界级 | 获得 XX 认证（需可证明）、广受认可 |
| 全网最低 | 限时优惠、详情见活动页 |
| 永久、永远 | 在合理期限内、在正常使用条件下 |

## 二、数据与效果宣称

1. **必须有出处**：销量、好评率、实验数据应注明来源、统计口径与时间范围。
2. **避免个体案例泛化**：「我用后完全好了」类用户证言不能替代产品功效证明。
3. **对比广告**：与竞品对比需客观、可验证，不得贬低竞争对手。

## 三、限时促销表述

- 可写：「活动截止 2026 年 6 月 30 日」「限量 500 份，售完即止」。
- 避免：虚构倒计时、长期「最后一天」、无依据的「仅剩 X 件」。

## 四、常见行业注意事项

### 化妆品

- 不得明示或暗示医疗作用，不得使用医疗术语。
- 「美白」「防晒」等需与注册/备案功效一致。

### 食品

- 普通食品不得宣传保健功能；保健食品不得宣传疾病预防、治疗功能。

### 金融理财

- 不得承诺保本保收益；需显著提示风险。

### 教育培训

- 不得对升学、考试结果作出保证性承诺；不得利用受益者的名义或者形象作推荐、证明。

## 五、审核清单（发布前自检）

- [ ] 是否含绝对化、最高级用语？
- [ ] 功效、数据是否有证明材料？
- [ ] 是否涉及医疗、疾病、治疗表述？
- [ ] 代言人/用户证言是否合规？
- [ ] 活动规则、价格、赠品是否清晰无歧义？
